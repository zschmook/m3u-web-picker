# League icons

These PNGs are bundled for the Sports Automation picker, so displaying league
artwork does not depend on third-party image hosts or an API key. `sources.json`
records the official league/federation page or ESPN league metadata that supplied
each original asset, its URL, and the catalog entries using it. Verified October
5, 2026.

Original artwork is scaled proportionally to a maximum 256-pixel box. Transparent
margins are trimmed; selected dark marks have a white backing for readability.
Inline SVG brand marks inherit their site's display color when rasterized. No SVG
scripts or external references execute in the application.

NCAA disciplines and divisions share the NCAA mark. Olympic disciplines share
the Olympic rings. Broad categories without a single governing brand retain the
picker's letter fallback. Existing minor hockey league and team marks remain in
`../hockey/`; AHL uses the circular emblem from its official website wordmark.

All league and organization names and marks belong to their respective owners.
