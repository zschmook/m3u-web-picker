Bundles the VPN host helper in the Windows, macOS, and Linux installers so connection tests and activation no longer require manually running Python scripts.

- Include a native VPN supervisor inside each installer, with its own bundled Python runtime and both VPN workers.
- Install it in a versioned private runtime folder, start it automatically, and register current-user login startup. Use a Windows current-user Run entry, macOS LaunchAgent, or Linux systemd user service with desktop-login fallback.
- Wait for Docker availability, restart failed workers, and prevent duplicate supervisors. Verify both worker heartbeats before declaring installation ready.
- During UP, finish owned helper operations before replacing source/runtime files and preserve the saved VPN graph, private credential volume, and application data.
- Accept the official release image in the connection manager, read the installed `.env` for later switches, and reuse the exact Gluetun image verified with the saved profile.
- Require the production container's Compose ownership to match the installed directory. The app does not receive the Docker socket, and no WireGuard keys are added to command arguments, environment variables, host configuration, or logs.
- Self-check the frozen helper and the helper extracted from the finished installer on every packaging platform.

Startup follows the current user's login/service-manager lifecycle; this release does not change Docker startup or enable Linux systemd lingering. Full fresh-machine/reboot acceptance, additional providers, and replacement of an active profile remain pending. The VPN remains a development preview while that coverage is completed.

Includes the VPN workflow, sports API, stream diagnostics, and credits changes released in v43.
