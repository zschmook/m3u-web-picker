Adds the VPN development preview and protected provider playback developed on port 9998.

- Drag and drop a WireGuard configuration, detect the provider when possible, and open official provider/setup/pricing links.
- Detect the host's actual LAN subnet rather than guessing a private-network range.
- Test tunnel connectivity, public IP, DNS, kill switch, recovery, and LAN/Tailscale host access in an isolated tunnel.
- Keep test uploads temporary; retain an applied configuration privately in a Docker volume across container recreation and updates.
- Relay exported provider streams through opaque Picker URLs, including HLS resources and playback with FFmpeg disabled.
- Add a VPN power/status control and green public IP in the sidebar. Settings enablement is separate from power on/off; an enabled but disconnected VPN blocks provider traffic.
- Preserve a managed VPN Compose graph during installer upgrades.

**Development preview limitation:** automatic testing, initial activation, and interactive switching currently require the port-9998 development host helpers. The packaged installers do not yet provision or supervise those helpers for general installations. This release does not advertise turnkey VPN setup. Normal installations can leave VPN disabled. See [VPN development notes](https://github.com/zschmook/m3u-web-picker/blob/v42/docs/VPN-DEVELOPMENT.md) for scope and remaining work.

Already applied VPN configurations recover through Docker/Gluetun restart policies without the helper. Full host reboot coverage, other installation targets, additional provider/device testing, and replacement of an applied profile remain pending.
