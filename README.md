# M3U Web Picker v17

Changes from v15:
- Bulk query actions are now directly under the search box.
- Buttons are named:
  - `Add all X`
  - `Remove all X`
- They only operate on the current query/filter results.
- Removed the confusing global Select All / Clear All idea from v16.
- EPG remains removed.

Run:
```bash
pip install -r requirements.txt
python app.py
```

Open:
```text
http://localhost:9999
```
